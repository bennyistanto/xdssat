# Course data of the 2018 DSSAT training (Chiang Mai)

Data files handed out with the exercises of the International Training Program on DSSAT, Chiang Mai
University, 27 August - 1 September 2018 (trainers Prof. Gerrit Hoogenboom and Prof. Attachai Jintrawet).
Only data are kept here; the course's PDFs and slides are not part of this repository.

| File | Exercise (day) | Used in |
|---|---|---|
| `GRGR-Raw.xls` | Weather data files with WeatherMan (day 2): Griffin, Georgia, 1992-1999, in inches, °F and cal/cm² | module 2 |
| `colorado/` (`GRCO0801/1001.MZX/.MZA/.WTH`, `GR.SOL`) | GLUE, self test 4 (day 2/3): Greeley, Colorado, maize DEKALB 52-59 AF; Anothai et al. (2013), doi:10.1016/j.agrformet.2013.03.001 | module 3 |
| `umariya_soil.csv` | Soil data files (day 3): Umariya series, typed from the course's analytical data sheet | module 3 |
| `orangeburg_soil.csv` | Soil data files (day 3): Orangeburg series pedon 2, typed from Perkins (1987), Characterization Data for Selected Georgia Soils, pp. 364-365 | module 3 |
| `PN_1976_Summary.xls`, `PN_1976_TimeSeriesData.xls` | Creating crop measurement files (day 4): 1976 peanut shading study; Hang et al. (1984), doi:10.2135/cropsci1984.0011183x002400010025x | module 4 |
| `NIGE1101.SNX` | Seasonal analysis, exercise 3 (day 5): millet at Tillabery, Niger | module 5 |

The two soil CSVs keep the sheet's numbers as printed. In the Umariya sheet, layer 11-31 cm adds up to
110% (55.2 + 18.4 + 36.4); module 3 shows how that is handled. Orangeburg water contents are % by weight.
